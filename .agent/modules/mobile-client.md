# Module: Mobile Client

## Status
**NOT IMPLEMENTED** as a mobile product surface.

The web app ships a PWA manifest. Layout uses a five-item bottom tab bar
(`MOBILE_TAB_ITEMS`: Home, Inbox, Library, Review, Tasks) on narrow
viewports, and Home / Space Today stack to one column below `md`. There
is no offline queue, no swipe card review, and no mobile-only capture
sheet.

Design notes: [unimplemented-from-guides.md](../plans/unimplemented-from-guides.md) §5.
