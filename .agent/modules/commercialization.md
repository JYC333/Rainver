# Module: Commercialization Scope

## Current fact

Rainver is a single self-hosted instance for personal, household, and
small-team use. The UI is the browser app (`apps/web`). There is no
billing, org SSO, plugin marketplace, or multi-tenant SaaS router.

Current data layout is the source repo plus `RAINVER_ROOT` /
`RAINVER_HOME` runtime roots — not a `core/` vs `instance/` tree.
